# Grade Check Website
#  
# ABOUT
#  
A website made specifically for students at Purdue University to track their grades accurately.
#  
# Project timeline:
#  
✓ 1. Create git repo 
2. Code the needed logic and math equations in Java
3. Make sure there’s a text interface that can be tested and function properly in Java before moving over to the web design
4. Form a basic skeleton using HTML and a little CSS
5. Implement Java code into JavaScript and test if everything works
6. Add more CSS to make the website look presentable
7. Get some other students to test the website on their own to see if it works for them
8. Implement a database to store larger data if needed 
9. Apply any finishing touches
#  
# MVP Scope: 
- Working code that uses real-time math equations to calculate the student's grade
- Student will need to find the percentage grade of each category and implement it into the system beforehand
- A data system that captures the student’s data and stores it for that specific student
- An interface that is accessible and works well enough for the student to navigate the website (no GUI/ text-based)
#  
# Future Plans:
- Beautiful GUI that is simple but effective enough for the student to navigate the website
- Using student emails and student names to store data 
- Allowing the student to enter every individual grade, while the program does all of the calculations itself
- Erasing all data before the next semester starts
#  
# Tech Stack:
- Java for basic coding before implementing code in JavaScript
- HTML, CSS, and JavaScript for website layout and design
- CSV file for storing data
- Possible use of an external database if a CSV file can’t store enough data
